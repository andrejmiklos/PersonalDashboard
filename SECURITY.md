# Security Policy

This is a personal, single-owner project. Only the latest `main` is supported.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(*Security* tab → *Report a vulnerability*).

Include steps to reproduce and the affected component (`worker`, `display`, `admin`). You can expect an
initial response within a week.

## Found a secret or personal data in the repository?

Report it privately the same way. The owner will rotate the credential first and only then clean the
history (see [docs/06-security-and-public-repo.md](docs/06-security-and-public-repo.md)).
